## Project description

The primary point and main goal of this project is to create a functional analog clock by using Java Script.

Another point noted was to **not edit** the **index.html** file in any perspective, so I was only premitted to create an extern CSS and Java Script file.

I created the base of the clock by using Java and designing the rim and the hands with CSS, though used trivial assets from the internet to create a cleaner design. I chose a clock face from the internet, aswell as a marmor background image from the internet.

I used few sides to get my inspiration off, for example **w3schools.com** and **uhrprogrammieren.com**.

## Details about the clock

The clock corresponds in real time, allowing users to see the current time in precisely every second. It has a responsive design, which allows it to be viewed on various devices and screen sizes.
